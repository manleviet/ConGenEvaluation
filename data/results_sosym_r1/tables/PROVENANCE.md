# Provenance

Generated by `reproduce_tables_sosym.sh`, generator fingerprint `fe5f4cc1584b`, clean.

The fingerprint is a SHA-256 over the bytes of the generator files, not a commit
id. Re-running this script recomputes it, so a reader who reproduces these tables gets
this file back unchanged; a differing fingerprint means the generating code differs,
which a commit id could not have told you. The commit this artifact was derived from
is recorded in the repository's root commit message.

## Input

Every table here is computed from `data/results_sosym_r1` — the acquisition results, each fold
scored against its own oracle. Both halves of the tree are inputs: `congen/`
carries the passive results and `interactive/` the iterative baseline, and a
table that draws a column from one and a stale copy of the other reproduces from
neither. The script asserts both are present before it emits anything.
